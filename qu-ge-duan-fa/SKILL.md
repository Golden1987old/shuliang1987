# 取格断法

## R — 原文 (Reading)

> 凡一字之来，用一语判之，谓之取格，如文章人品之有定论也。法先详其五行生克，次观其六神动静。假若五行相生、六爻安静，则取吉格断之，否则以凶格断之。其断语皆当出经入史，搜神剔髓，字字珠玑，笔笔风雅，方妙此不传之秘也。
>
> — 程省，《测字秘牒》卷三 测字取格大法

---

## I — 方法论骨架 (Interpretation)

取格断法是测字术中"从分析到结论"的最后一公里。它的核心逻辑分三层：

1. **定五行**：看字的偏旁部首，归入金木水火土。如"氵"属水、"火"属火、"金"属金。这是判断的底层坐标。
2. **查生克**：五行之间有生（促进）有克（制约）。相生则吉，相克则凶。如水生木为吉，火克金为凶。
3. **观六神**：在五行判断的基础上，再用六神（青龙、朱雀、勾陈、螣蛇、白虎、玄武）标记字的各部分。青龙、朱雀主吉，白虎、玄武主凶，勾陈、螣蛇主纠缠反复。
4. **出断语**：综合五行生克和六神状态，用一句精炼的话给出定性判断。断语要求"出经入史"——有依据、有文采、切中事理。
5. **补充形式**：一句不够时用双句格（两句递进）；需要灵活组合时用散格法（按偏旁积木式拼装断语）。

掌握这套方法，就能把"字形拆解"转化为"吉凶判断"，把模糊的直觉变成可复现的推理链。

## A1 — 书中的应用 (Past Application)

### 案例 1: 张字问官司——吊客当头（六神断法）
- **问题**: 汪四被总宪拿问，友人写"张"字问能否获释。
- **方法论的使用**: 程省取格断"吊客当头，丧门煞局，内中王心已偏"。"张"字拆出"弓"（丧门形）、"长"（吊客形），"弓"中藏"王"但心已偏。综合六神判断为极端凶象。
- **结论**: 性命难保，更不用想获释。
- **结果**: 十月终汪四果然自缢于狱中。

### 案例 2: 麟字问终身——贵人之格（五行+笔迹综合断法）
- **问题**: 一人写"麟"字问终身运势。
- **方法论的使用**: 程省见笔迹"肥浓、横直停匀而有神采"，断为贵人之格。"麟"字含"鹿"（禄象）、"粦"（火象），字有戈戟之形断为元戎之位。五行属纯水形，宜北方不利南方。
- **结论**: 袭职之官，妻宫寂寞，寿止六旬。
- **结果**: 其人果为京口郭某，广东水师参将，二十四克妻，十五年百事不遂。

### 案例 3: 幸字问病——三不幸（五行生克断法）
- **问题**: 一人写"幸"字问病人（四十九岁）吉凶。
- **方法论的使用**: 程省断"幸字反有三不幸"：①问病不宜见土与木，今数中土木交加；②木中桑木最坚久，今不成桑木；③不完五十。五行上土木交加克本体，综合断凶。
- **结论**: 若挨过八月至十月方可谓幸。
- **结果**: 一月后果卒。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户已经完成字形拆解（用测字十法），现在需要一句话给出吉凶判断。
2. 用户问"这个字五行属什么""偏旁代表什么""六神怎么看"等取格体系相关问题。
3. 用户需要断语——一个精炼的、有文采的结论，而不是零散的分析。

### 语言信号 (用户的话里出现这些就应激活)

- "这个字断吉凶" / "give a verdict on this character"
- "取个格" / "set a frame for this"
- "帮我下个断语" / "write a judgment phrase"
- "五行怎么看" / "what's the five-element reading"
- "六神怎么断" / "how do the six spirits apply"
- "偏旁代表什么" / "what does the radical mean"

### 与相邻 skill 的区分

- 与 `ce-zi-shi-fa`（测字十法）的区别：十法负责字形拆解操作（怎么拆），取格断法负责吉凶判断（拆完之后怎么断）。十法是"工具箱"，取格是"裁判"。
- 与 `xin-yi-liu-fa`（心易六法）的区别：六法负责字义推导逻辑（怎么从字形推到含义），取格负责把推导结果转化为定性判断。六法是"推理引擎"，取格是"输出格式"。
- 与 `yi-zi-yi-ji`（一字一机）的区别：一字一机强调"同字不同断"的情境唯一性原则，取格强调"有固定流程可循"的结构化判断。一字一机是"总原则"，取格是"具体方法"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别偏旁，定五行归属**
   - 看字的主要偏旁部首，归入金/木/水/火/土。
   - 完成标准：能明确说出"此字偏旁为 X，五行属 Y"。
   - 参考：氵→水、火/灬→火、金/钅→金、木/艹→木、土→土。

2. **判断五行生克关系**
   - 如果字中有多重五行，判断它们之间是相生还是相克。
   - 相生（木→火→土→金→水→木）则吉，相克（木→土→水→火→金→木）则凶。
   - 完成标准：能说出"X 生 Y，主吉"或"X 克 Y，主凶"。

3. **标记六神状态**
   - 将字的各部分（头、身、脚、尾）对应六神：青龙（吉）、朱雀（口舌）、勾陈（纠缠）、螣蛇（惊恐）、白虎（凶险）、玄武（小人/暗昧）。
   - 完成标准：能说出字的哪些部分对应哪些六神，综合判断吉凶。
   - 判停条件：若字形简单、无法明确对应六神，则跳过此步，仅以五行生克断之。

4. **产出断语**
   - 综合前三步，用一句精炼的话给出定性判断。
   - 若一句不够，用双句格（两句递进，如"有容乃得宽舒，无学难为先觉"）。
   - 断语要尽量做到：有依据（来自五行/六神分析）、有文采（出经入史）、切中事理（与问事相关）。
   - 完成标准：用户拿到一句可直接使用的断语。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **字形尚未拆解时**：取格的前提是有明确的偏旁/五行归属。如果字还没拆，先用测字十法拆解。
- **纯粹的直觉判断场景**：如果用户要的是"心镜光明"式的直觉感知，那是观梅心法的领域，不是取格。
- **字形过于简单、无法对应五行时**：如"一""丨"等极简字，偏旁不足以定五行，此时取格法不适用。

### 作者在书中警告的失败模式

- **六神齐犯** (ce10)：当一个字的各部分同时对应多个凶神时，凶险程度远超单一凶神。"凫"字问官司，枭神头、白虎脚、勾陈身、螣蛇尾，四凶齐犯，断"夹打俱有"。教训：必须全面扫描字的各部分，不能只看局部就下结论。
- **取格之难** (ce11)：取格要求断语"出经入史，搜神剔髓，字字珠玑，笔笔风雅"。初学者勉强取格，往往断语粗俗、逻辑牵强。教训：取格门槛极高，初学者应先从散格法（积木式拼装断语）入手，逐步提升到单句格、双句格。

### 作者的盲点 / 时代局限

- **五行对应过于依赖偏旁**：程省的五行归属几乎完全靠偏旁部首判断，但很多字的偏旁与五行的对应关系并不明确（如"心"属什么？"口"属什么？），书中对此缺乏系统说明。
- **六神与偏旁的映射未标准化**：六神（青龙/朱雀/勾陈/螣蛇/白虎/玄武）与具体偏旁/笔画的对应关系，在书中主要靠案例呈现，缺乏一张完整的映射表。不同案例中的对应方式偶有不一致。
- **断语标准过高**："字字珠玑，笔笔风雅"的要求使得取格法几乎成了"文学创作"而非"技术操作"，普通学习者难以达到。

### 容易混淆的邻近方法论

- **取格 vs 散格**：取格是用一句话整体断之，散格是按偏旁逐个拼装断语片段。取格更精炼但更难，散格更灵活但更碎。
- **取格 vs 双句格**：双句格是取格的"降级版"——当一句话说不完时用两句。不是独立方法，是取格的补充形式。
- **五行断法 vs 六神断法**：两者是取格的两个子步骤，不是独立方法。先五行后六神，有先后之序。
