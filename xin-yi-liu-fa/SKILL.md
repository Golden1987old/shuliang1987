# 心易六法

## R — 原文 (Reading)

> 象形、会意、假借、谐声、指事、转注——借庖羲之六义以垂示后学。如临字问病，断不吉，则曰临丧，临乃去声也。王字问求财，断曰旺相，王乃去声读之。一字千金信有之，奇中有正正中奇，五行八卦供吾后，此段天机不易知。
>
> — 程省, 《测字秘牒》卷二·心易六法

---

## I — 方法论骨架 (Interpretation)

心易六法借用汉字六书的名称，建立了一套从符号推导含义的多维解读框架。六法各自独立又互补：

1. **象形**：看字形像什么——像物、像另一字、像某种意象（如"弓"似蛇，"辛"似"幸"）
2. **会意**：把字的整体意象联想为一个场景故事，再从故事推导结论（如"烟"→因风吹火→借力方成）
3. **假借**：同一个字在不同情境下借用不同含义（如"立"逢人借为位，遇水借为泣）
4. **谐声**：借同音字转换含义（如"梨"谐"离"，"秤"谐"称"）
5. **指事**：不看字形，看问字者的人、色、言、事等外在信息来辅助判断
6. **转注**：一字多音多义，根据需要选择最契合的那个读法/含义（如"王"读去声为"旺"）

核心逻辑：面对一个符号，不要只取一种解读，而是从形、意、境、音、事、义六个通道同时扫描，找到与当下情境最契合的那个含义。六法不是文字学的六书，而是测字实战中的六种语义推导路径。

## A1 — 书中的应用 (Past Application)

### 案例 1: 焉字问病——象形测法（似马非马）
- **问题**: 有人写"焉"字问病人情况
- **方法论的使用**: 程省用象形法分析：焉字"似马非马"——像马但不能行动；"似为非为"——像"为"字但不是"为"，故服药无用
- **结论**: 瘫症，不能行动，药石无灵
- **结果**: 其人果然疯瘫四年

### 案例 2: 非字问谋事——谐声测法（韭芽之利）
- **问题**: 有人写"非"字问谋事能否成功
- **方法论的使用**: 程省用谐声法分析：非谐"韭"——韭芽自春至秋不绝，其利故大；非又为"纤"字之心，故四面纤巧事皆从心而起
- **结论**: 事已成，且有大利，四面纤巧
- **结果**: 其人果然得利

### 案例 3: 临字问病——转注测法（临去声为丧）
- **问题**: 有人写"临"字问病人吉凶
- **方法论的使用**: 程省用转注法分析：临字读平声为"来临"之义，读去声则为"临丧"之义。问病不吉，故取去声
- **结论**: 不吉，临丧之象
- **结果**: 转注法示例，展现一字多音多义的灵活选择

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户拿到一个字/符号/名字，想从多个角度理解其深层含义，而不是只做表面拆解
2. 用户遇到多义字，不确定在特定情境下该取哪个含义
3. 用户想分析一个品牌名、Logo、标志的多层语义，需要系统化的解读框架
4. 用户在做测字/占卜/文化分析时，已经会拆字形，但想进一步从"字义"层面深入

### 语言信号 (用户的话里出现这些就应激活)

- "这个字/名字有什么含义？" / "What does this character/name mean?"
- "从哪些角度理解这个字？" / "How many ways can I interpret this?"
- "这个多义字该取哪个意思？" / "Which meaning should I pick for this polysemous word?"
- "六法""六书""字义分析""多层含义" / "six methods""semantic analysis""multi-layer meaning"
- "谐音是什么？""象形怎么看？""这个字像什么？"

### 与相邻 skill 的区分

- 与 `ce-zi-shi-fa`（测字十法）的区别: 测字十法操作的是字形结构（添笔、减笔、拆解等物理操作），心易六法操作的是字义/语义（形→义、意→义、音→义等意义推导）。十法是"怎么动字"，六法是"怎么读字"。
- 与 `qu-ge-duan-fa`（取格断法）的区别: 取格断法是用五行六神将字义转化为吉凶断语，心易六法是获取字义本身的多维解读。六法是"取义"，取格是"断吉凶"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别目标符号，初步扫描六法通道**
   - 拿到目标字/符号后，逐一检查六法是否适用：字形像什么（象形）？整体意象是什么场景（会意）？有没有谐音可借（谐声）？有没有多音多义可选（转注）？周边环境有没有可借用的信息（假借）？问字者的外在表现如何（指事）？
   - 完成标准: 至少识别出 2-3 种对该字适用的六法通道

2. **选择最契合情境的 1-2 种六法深入推导**
   - 不要六法全部展开，选择与当前问事情境最相关的 1-2 种深入分析
   - 完成标准: 选定的六法通道有明确的推导链（如：字形→所像之物→所含寓意→与问事的关联）
   - 判停条件: 若字形过于简单或情境信息不足，可退回到"测字十法"做字形操作后再回来

3. **综合推导，给出字义层面的解读结论**
   - 将 1-2 种六法的推导结果综合，给出对目标符号的多维语义解读
   - 若需进一步判断吉凶，可衔接"取格断法"
   - 完成标准: 用户能理解该符号在当前情境下的核心含义，且推导过程有理有据

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯字形操作需求**: 用户只想拆字、添笔、减笔，不关心字义层面的多维解读 → 用"测字十法"
- **需要明确吉凶判断**: 用户已经知道字义，只需要吉凶断语 → 用"取格断法"
- **情境信息完全缺失**: 无问事者、无问事目的、无环境信息 → 六法中的假借和指事无法运作，只能用象形和会意做基础解读

### 作者在书中警告的失败模式

- **照搬前例致断** (ce01): 同一个字不同人问，含义完全不同。不能因为上次"焉"字断瘫症，这次"焉"字也断瘫症。每次都要重新走六法推导，结合当下情境。
- **字面取义致误** (ce03): "磨"字不能因为"消磨"的常用词义就断凶——测字取义基于字形结构和六法推导，不是基于词语含义。六法中的会意是看字的整体意象，不是查字典。
- **机械拆字致断** (ce02): 不能只看字形拼合的表面意思（如"火+水=淡=财气淡泊"），必须结合实际情况综合判断。六法是推导路径，不是算术公式。

### 作者的盲点 / 时代局限

- **六法借用六书之名，但含义已扩展** (p12): 作者明确说"借庖羲之六义以垂示后学"，但六法的实际含义与文字学的六书有明显差异——测字的"象形"比六书的象形宽泛得多（含以物象字、以字象字、以意象字），"转注"被重新定义为一字多音多义的选择。读者不可将六法等同于文字学六书。
- **谐声法依赖方言语音**: 谐声法的谐音对应（如"秤"谐"称"、"梨"谐"离"）基于清代官话或方言，不同方言区可能有不同的谐音关系，直接套用可能失准。
- **指事法中"正论勿好奇"的矛盾**: 作者一方面鼓励灵活应变，一方面又要求"正论勿好奇"——但六法本身就是在"好奇"（寻找非显而易见的含义）。这个张力在书中未被充分讨论。

### 容易混淆的邻近方法论

- **与文字学六书的混淆**: 六书（象形、指事、会意、形声、转注、假借）是文字学的造字分类，六法是测字的语义推导路径。名称相同但目的和操作完全不同。
- **与测字十法的混淆**: 十法是字形操作（装头、接脚、破解等），六法是字义推导（象形、会意、谐声等）。两者互补但不重叠——十法改字形，六法读字义。
