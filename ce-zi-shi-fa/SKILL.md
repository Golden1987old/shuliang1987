# 测字十法

## R — 原文 (Reading)

> 测不立法，不足以示学者之权衡；字不加减，不足以开问者之蒙昧。是必乘除损益每一字到真机，流动变化数字于其间，则所问之事昭然在目。列法于左：装头、接脚、穿心、包笼、破解、添笔、减笔、对关、摘字、观梅。
>
> — 程省，《测字秘牒》卷一

---

## I — 方法论骨架 (Interpretation)

面对一个字（或符号），不能只看它的静态外观——必须对它做"操作"，才能让隐藏信息显现。程省提供了十种标准化操作，构成一个完整工具箱：

1. **装头**：从上方添笔，让"藏首"显现（如 戊→茂、日→春）
2. **接脚**：从下方添笔，让"未举足"者行动（如 采→悉、千→秀）
3. **穿心**：主体不动，从中间穿入新要素（如 文→吏、昌→量）
4. **包笼**：主体不动，外围包裹形成新整体（如 玉→宝、牛→逄）
5. **破解**：劈开字形重组（破）+ 从旁抉出评论成文（解）——破易解难
6. **添笔**：泛指补不足，不限位置（如 王→玉、才→财）
7. **减笔**：略损有余，但不可滥用（如 宽→见、莫→草）
8. **对关**：取首尾如开关门，最简捷用最广，为"字中第一要义"（如 先→牛头虎足、善→美头喜足）
9. **摘字**：只取一二小笔画来断，粒度最细（如 哉→土/戈、调→吉/司）
10. **观梅**：超越固定程式，以"心镜光明"直觉感知——最高境界，不可直接操作

核心逻辑：字不是死的符号，而是可以通过加减拆合来"激活"的信息体。选哪种操作，取决于字的结构特征和所问之事。

## A1 — 书中的应用 (Past Application)

### 案例 1: 笔字问终身——对关法（c20）
- **问题**: 周龙携"笔"字问终身运势
- **方法论的使用**: 用对关法拆出"笃字头、律字尾"，中一竖有精神。头尾合断：笃实守律、有主心骨
- **结论**: 逢丑年交鸿运，十二年顺利，早年为入幕之宾，妻迟子晚
- **结果**: 果为幕友邵令铭所书，二十八岁未婚，作幕数年

### 案例 2: 磨字问风水——对关法 + 破解法（c37）
- **问题**: 有人写"磨"字问墓地风水吉凶
- **方法论的使用**: 用对关拆出"历字头、磐字尾"——历年悠久如磐之安。破解法拆出"一点为墓主、石为墓碑、林为树木"
- **结论**: 吉地，葬后二十四年当发解元，历官知府
- **结果**: 问事者以"消磨"为不吉反驳，程省反驳："设若书一仙字便能成仙，书一鬼字即能见鬼乎？"——字形结构≠词语含义

### 案例 3: 公字问事——对关法 + 六神断法（c28）
- **问题**: 有人写"公"字问合伙之事，因等待太久欲转身走
- **方法论的使用**: 用对关拆出"分字头、去字脚"——必与人共事、欲分头而去。末笔带玄武，有小人刁唆
- **结论**: 劝止分账，否则将见官司
- **结果**: 其人依言，旬日后表兄主动许诺来岁分店各开，相安无事

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户给出一个汉字/名称/品牌名，问"这个字/名字好不好"、"有什么含义"、"拆开看是什么"
2. 用户面对一个符号或名称，想从中提取隐藏信息或判断吉凶
3. 用户在做命名、选号、择字等决策，需要字形层面的分析

### 语言信号 (用户的话里出现这些就应激活)

- "测这个字" / "帮我拆一下这个字"
- "这个字怎么看" / "字里有什么信息"
- "analyze this character" / "what does this name/character reveal"
- "break down this word" / "character analysis"
- "这个名字好不好" / "字形上有什么讲究"

### 与相邻 skill 的区分

- 与 `心易六法` 的区别：十法操作的是**字形结构**（加减拆合），六法操作的是**字义推导**（象形会意谐声等）。先用十法改变字形，再用六法解读含义
- 与 `取格断法` 的区别：十法产出的是"变形后的字"，取格产出的是"一句话吉凶判断"。十法是中间步骤，取格是最终输出
- 与 `观梅心法` 的区别：前九法有明确操作规则可教可学，观梅是"无法之法"依赖直觉，不可标准化

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **识别字形特征**
   - 观察用户给出的字/符号的结构：上下左右是否有藏头露尾？是否有可拆分的部件？笔画是否有冗余或不足？
   - 完成标准：能描述该字的结构特征（如"上部封闭""中部可穿""整体可拆"等）

2. **选择操作方法**
   - 按优先级尝试：①对关（首选，最简捷）→ ②装头/接脚（上下添笔）→ ③穿心/包笼（不动主体）→ ④破解（拆解重组）→ ⑤添笔/减笔（微调）→ ⑥摘字（精细取笔画）
   - 判停条件：若字形明显适合某一法（如首尾分明用对关、上部隐藏用装头），直接进入步骤 3
   - 注意：减笔法需谨慎——"非事之当而理之正，不可漫然用之"（p04），减得过多会混入摘字法

3. **执行操作并解读**
   - 对字执行选定的操作，得到变形后的字或部件
   - 用会意/象形/谐声等方法解读变形结果的含义
   - 结合用户所问之事，给出判断

4. **综合取格（可选）**
   - 若需要一句话定性判断，参考散格法的断语片段组合出格言式结论
   - 完成标准：断语简洁有力，有字理依据

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯语义查询**：用户问"这个字什么意思"时不需要拆字，直接查字典即可
- **书法鉴赏**：笔迹分析（肥瘦浓淡）是辅助维度，不属于十法操作范围
- **初学者强行用观梅法**：观梅是"心诀"而非"程式"，没有固定规则可循，"存乎其人"（ce06）

### 作者在书中警告的失败模式

- **减笔滥用（ce04）**："减笔一法，非事之当而理之正，不可漫然用之也。凡当减时，亦当略减方是。不然，混入摘字法矣。"——减笔必须有正当理由，只能略减，否则方法混淆
- **破解失度（ce05）**："破易而解难，破平正而解奇幻。"——只做物理拆分（破）不做意义解读（解），断语会空洞无物。破是手段，解是目的，二者缺一不可

### 作者的盲点 / 时代局限

- **托古邵康节**：全书多次引用"邵子曰"来增强权威性，但大量断法实为程省本人经验总结。邵康节（邵雍）的《梅花易数》中并无系统的测字十法，程省有"托古"之嫌
- **断语标准过高**：取格要求"出经入史，搜神剔髓，字字珠玑，笔笔风雅"，这一标准几乎只有文学修养极高的人才能达到，对普通学习者构成隐性门槛
- **观梅法的不可习得性**：作者承认观梅法"存乎其人"，等于承认最高境界的方法无法通过书本传授，这在方法论上是一个根本性的缺口

### 容易混淆的邻近方法论

- **减笔 vs 摘字**：减笔是"略减"后仍成完整字；摘字是只取一二小笔画。操作相似但粒度不同，减笔过多就变成摘字
- **穿心 vs 破解**：穿心"字体不动"、破解"必须分开"。区分标准是：原字结构是否保持完整
- **装头/接脚 vs 添笔**：装头和接脚是添笔的特例（限定了添加方向），添笔是不限位置的上位概念
