# 一字一机

## R — 原文 (Reading)

> 先一飒字，适我起立，东风拂面，故即用天机之发以应之。复一人亦指飒字问行人……内犯玄武，外带勾陈，安得能来？又一人仍复将飒字问行人……旁人因问曰："先生何以三数同事同字，而断法不同，又皆应验，其理何据？"余曰："此机耳！夫字之来当观吉凶之变化，若心镜光明，无响不应。"
>
> — 程省，《测字秘牒》卷七·至理测法

---

## I — 方法论骨架 (Interpretation)

同一个字，三个人问同一件事（行人何时来），得出三个完全不同的结论——朝暮当来、不能来、三天后至——且都应验。这不是测字术的漏洞，而是它最深刻的操作原则：**一字一机**。

核心逻辑如下：

1. **字不是容器，而是镜子**。字本身不携带固定答案；它在特定时空情境下"映照"出当下的信息。同一个"飒"字，第一次测时东风拂面（天机发动），第二次问事者已过端面（濡毫之象），第三次三天后逢辛日——每一次的"机"都不同。

2. **情境是输入的一部分**。测字的输入不仅是字形本身，还包括：问字者是谁、什么时间问、什么动机问、测字者当时的状态、周围环境的变化。这些"活信息"共同决定了判断方向。

3. **照搬前例是最致命的错误**。"元"字前人四笔写成（偶数→生女），后人三笔写成（奇数→生男）。不分析当次书写的具体特征，机械套用上次结论，必然大错。

4. **因此，每次分析都是独一无二的**。没有"这个字的标准答案"，只有"这个字在此时此地此人面前的唯一正确答案"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 飒字三问行人——同字三断皆验
- **问题**: 三个不同的人先后用同一个"飒"字问行人何时归来
- **方法论的使用**:
  - 第一人：程省正起立，东风拂面，以"天机之发"应之→断"朝暮当来"
  - 第二人：问事者已过端面濡毫，字中内犯玄武、外带勾陈→断"人不能来，逃亡去也"
  - 第三人：三天后逢辛日→断"三天后至"
- **结论**: 同字三断，三个完全不同的答案
- **结果**: 三个判断皆应验。旁人惊叹问理，程省答："此机耳！"

### 案例 2: 元字问六甲——笔画奇偶决定生男生女
- **问题**: 两人先后用"元"字问生男生女
- **方法论的使用**:
  - 前一人"元"字四笔写成（二横如桥），数属偶→断生女
  - 后一人"元"字三笔写成（头尾昂藏），数属奇→断生男
  - 另一测字者不察字理，照搬前例断"生男"，结果大错
- **结论**: 同字同问事，因书写方式不同（笔画奇偶），断法相反
- **结果**: 前者生女，后者生男。照搬者误断

### 案例 3: 门字问病与问功名——同字不同事，吉凶相反
- **问题**: 两人分别用"门"字问不同事项
- **方法论的使用**:
  - 问病者：门字之形"日有余、月不足"，月代表阴/女，月不足则阴气将尽→断必死
  - 问功名者：门可开可闭，冬令天地闭藏如门之闭，春令万物萌芽如门之开→断功名大利但行期迟至春天
- **结论**: 同一"门"字，问病则凶、问功名则吉，因事不同而断法不同
- **结果**: 病人十四日后亡；问功名者新正后果出行

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **用户质疑"同字不同断"的合理性**——"为什么上次测这个字是吉，这次是凶？""测字不是应该有标准答案吗？"
2. **用户试图套用历史结论**——"上次'元'字断的是生男，这次也应该是吧？""这个字我之前问过，答案还记得。"
3. **用户不理解情境对判断的影响**——"我写的是同一个字啊，为什么你跟上次说的不一样？"

### 语言信号 (用户的话里出现这些就应激活)

- "同一个字为什么答案不同？"
- "上次这个字不是说……吗？"
- "Why does the same character give different readings?"
- "测字有没有标准答案？"
- "字同事不同"
- "一字一机"

### 与相邻 skill 的区分

- 与 `ce-zi-shi-fa`（测字十法）的区别：十法是字形操作的工具箱（怎么拆、怎么加减），一字一机是操作的前提原则（为什么同字要异断）
- 与 `xin-yi-liu-fa`（心易六法）的区别：六法是字义推导的六种路径，一字一机是为什么同一条路径在不同情境下会通往不同终点

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别"同字"情境**
   - 判断用户是否在比较两次或多次同字的分析结果
   - 完成标准: 明确用户是在问"为什么同字不同断"，还是在试图套用前例

2. **指出情境差异**
   - 逐一列出每次分析中不同的变量：问事者不同、时间不同、所问事项不同、字的书写方式不同（笔画数、姿态、墨迹）、测字时的环境不同
   - 完成标准: 用户能理解"同字"只是表面相同，底层输入完全不同
   - 判停条件: 若用户已经理解情境差异，直接跳到步骤 3

3. **解释"一字一机"原则**
   - 引用飒字三断或元字生男女的案例，说明每次分析的"机"（时机、机缘、机关）都是独一无二的
   - 用类比帮助理解：同一面镜子在不同光线下映出不同景象，不是镜子变了，而是光线变了
   - 完成标准: 用户理解"没有标准答案，只有当下唯一正确答案"

4. **防止照搬误断**
   - 如果用户试图套用历史结论，明确指出这是最致命的错误（引用 ce01 反例）
   - 引导用户回到当次分析的具体情境中来
   - 完成标准: 用户放弃套用，愿意基于当前情境重新分析

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户在问字义/词义**：查字典式的字义查询不涉及情境判断，不需要一字一机原则
- **用户在做固定规则的字形分析**：如拆字练习、偏旁归类等标准化操作，情境唯一性不适用
- **用户在学习基础测字技法**：初学者需要先掌握固定规则（十法、六法），过早引入"无标准答案"会造成混乱

### 作者在书中警告的失败模式

- **ce01 照搬前例致断**：另一测字者不察"元"字的笔画奇偶差异，照搬前例结论断"生男"，实际生女。核心教训：同字≠同断，必须分析当次书写的具体特征。
- **ce07 同字不同断的规则局限**：飒字三断暴露了"固定字-义对应表"的根本缺陷——同一字的断法可以无限多，规则无法穷尽。试图用查表法覆盖所有情况必然失败。

### 作者的盲点 / 时代局限

- **"机"的不可验证性**：程省将同字异断归因于"天机"（东风拂面、三日后逢辛等），但这些"机"的识别完全依赖测字者的主观感知，无法客观验证或传授。作者用"心镜光明"来解释准确性，但这本质上是循环论证——准确是因为心镜光明，心镜光明的证据就是准确。
- **幸存者偏差**：书中只记录了应验的案例，未记录同字异断但不应验的情况。飒字三断皆验可能是精选结果，不代表该方法的普遍准确率。
- **托古权威**：作者将核心原则归于邵康节（"邵康节先生曰"），但邵雍的《梅花易数》中并无"一字一机"的明确论述，这是程省自己的经验总结，借邵子之名增强可信度。

### 容易混淆的邻近方法论

- **转注多义法（f09）**：一字多音多义，选择不同义项得出不同结论。区别在于：转注是字本身有多义性，一字一机是情境赋予字不同的"机"——即使字义完全相同，情境不同结论也不同。
- **假借测法（f07）**：同一个字在不同环境下借用不同含义。区别在于：假借是字旁的环境物改变含义，一字一机是更广泛的时空情境（包括时间、问事者、测字者状态等）改变判断。
